## React-basic-labs - Tasky.app

Tasky is a simple task management application built with React and Material UI.

<img width="1150" height="761" alt="image" src="https://github.com/user-attachments/assets/89b5cc84-f168-40e5-b487-d0f3dcb84437" />


The app allows users to create new tasks, mark tasks as completed, and delete tasks. Each task displays a title, deadline, and description.

Material UI components are used to style the application, including Cards, Buttons, Grid, Icons, and Chips. The layout is also responsive, so task cards adjust depending on the screen size.

The project was created as part of the Web App Development 2 module to practise React components, state management, event handling, responsive layouts, and Material UI styling.

### Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Display task deadlines
- Responsive layout
- Material UI styling and icons
